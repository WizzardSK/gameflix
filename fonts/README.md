Wine Tahoma (`WineTahoma.ttf`, `WineTahoma-Bold.ttf`) from the Wine project (fonts/tahoma.ttf and fonts/tahomabd.ttf in https://gitlab.winehq.org/wine/wine), a free replacement for Tahoma with the same metrics, based on Bitstream Vera Sans. Licensed under the GNU LGPL 2.1 or later, see `LICENSE-Wine.txt`.

`style.css` uses the installed Tahoma first and falls back to these files where it is missing (Linux, Android).
